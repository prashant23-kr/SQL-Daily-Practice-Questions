
# SQL Daily Practice Questions

A collection of **30 MySQL practice questions and solutions** designed to strengthen SQL fundamentals through hands-on practice.

This repository covers beginner to intermediate SQL concepts, making it useful for students preparing for placements, coding assessments, and SQL interviews.

---

## 📌 Topics Covered

- Database Creation
- Table Creation
- INSERT Statements
- SELECT Queries
- WHERE Clause
- ORDER BY
- LIMIT
- DISTINCT
- Aggregate Functions
  - COUNT()
  - SUM()
  - AVG()
  - MIN()
  - MAX()
- GROUP BY
- HAVING
- Aliases (AS)
- NULL & NOT NULL
- Basic SQL Interview Questions

---

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/SQL-30-Practice-Questions.git
```

### Open in MySQL Workbench

1. Open MySQL Workbench.
2. Open the `30 QUESTION SQL.sql` file.
3. Execute the queries.
4. Review the outputs.

## 📖 Sample Questions

- Find all employees.
- Display employees with salary greater than 50,000.
- Find the average salary.
- Count employees department-wise.
- Find the highest salary in each department.
- Display departments having more than one employee.
- Find departments where maximum salary is greater than 55,000.
